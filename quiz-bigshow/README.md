# Большая игра — квиз на Layero Data API

Темы × номиналы. Ведущий открывает клетку, все участники видят вопрос
**одновременно**, отвечают, счёт считает база.

Ни строчки бэкенда: вся логика — функции в схеме `api`, статика — один
`index.html` без сборки и зависимостей.

## Что здесь показано

**Данные закрыты по-настоящему.** Таблицы лежат в схеме `app`, и участнику не
выдано на них ни одного гранта — правильные ответы недостижимы анонимным
ключом даже перебором:

```
GET /<база>/rest/v1/cells?select=question,answer
→ таблица «cells» не найдена; каталог читается под ролью …_anon
```

Вся поверхность участника — три функции: `quiz_join`, `quiz_watch`,
`quiz_answer`.

**Честность показа.** Вопрос не отдаётся никому, пока не наступил `reveal_at`;
клиент подгадывает запрос ровно к этому моменту, а время думания считает
сервер от показа, а не от прихода пакета. Замер: сорок участников получают
вопрос с разбросом меньше 200 мс.

**Опрос, а не push.** Две ручки вместо одной, и это главное решение:
`quiz_watch` крошечная, без токена, одинаковая для всех — её зовут залпом в
момент показа; `quiz_state` тяжёлая (доска, счета, моё состояние) — её зовут
лениво раз в четыре секунды. Платить агрегатами по всей игре сорок раз за
секунду ради одной строки с вопросом было главной ошибкой первой редакции.

**Отказы разного смысла — разные отступы.** `503` от шлюза это обратное
давление: он отказывает сразу, чтобы всплеск не стал лавиной, и повтор уместен
через десятки миллисекунд. `429` от edge — переполненное ведро частоты, общее
на весь адрес: комната за одним Wi-Fi это ОДИН адрес, и частый повтор туда
только доливает.

## Как играть

Открыть <https://quiz-bigshow.layero.app/>.

1. Ведущий жмёт **«Провести игру»** → **«Создать»**. На экране появляется код
   из шести знаков — его называют участникам. Токен ведущего браузер
   запоминает сам, переписывать его руками не надо.
2. Участники открывают тот же адрес, жмут **«Играть»**, вводят код и имя.
3. Ведущий кликает клетку на доске. Через три секунды вопрос появляется у
   всех — одновременно.
4. Участники отвечают, ведущий жмёт **«Закрыть и начислить»**.

Обновление страницы игру не теряет: и ведущему, и участнику предлагается
**«Вернуться»**.

## Своя копия

```bash
# схема, функции и гранты — в свою базу
psql "<строка подключения>" -f schema.sql
# адрес базы и публичный ключ — в начало index.html
npx layero@latest deploy
```

Пакет вопросов подставляется по умолчанию; свой можно вставить JSON'ом прямо
в форме создания.

⚠️ Игру у этого примера может завести кто угодно, открывший сайт: `quiz_new`
выдан анонимной роли осознанно — иначе ведущему пришлось бы брать код и токен
из чужой консоли, и приложения бы не было. Границы стоят на размере пакета и
на лимите частоты, а не на правах.
