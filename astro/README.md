# Astro на Layero

Минимальный [Astro](https://astro.build) сайт, готовый к деплою на
[**Layero**](https://layero.ru) — российском хостинге фронтенда.

```bash
npm install
npm run dev        # локально: http://localhost:4321
npx layero@latest deploy   # деплой на Layero → публичный URL
```

Layero соберёт Astro и отдаст статику через CDN в России. Git не требуется.

Подробнее: <https://docs.layero.ru> · npm: <https://www.npmjs.com/package/layero>
