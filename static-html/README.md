# Статический HTML на Layero

Самый простой случай — папка с `index.html`, без сборки. Деплой на
[**Layero**](https://layero.ru):

```bash
npx layero@latest deploy
```

CDN и серверы в России, HTTPS на поддомене `*.layero.ru` из коробки.

Подробнее: <https://docs.layero.ru> · npm: <https://www.npmjs.com/package/layero>
